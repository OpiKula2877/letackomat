Co hlídat

Oznámí každý produkt, který má slovo v názvu, třeba každé pití s názvem Jägermeister.

    Akce, které jsou ve slevě už teď, ti nepřijdou jako oznámení. Uvidíš je tady u pravidla. Oznámení přijde u dalších nových akcí.

    Aktualizuji

    Server neběží

    Letáčkomat potřebuje běžící server. Jakmile se spustí, stránka se obnoví sama.

    Spustit server

    Tlačítko Spustit server funguje po jednorázovém spuštění install-start-button.bat. Jinak server spusť dvojklikem na start.bat.
