# Letáčkomat

Letáčkomat ukazuje akční ceny ze všech českých obchodů z kupi.cz na jednom místě. Vybereš den nebo období, obchody, kategorii a podkategorii a sestavíš si nákupní seznam. U produktu porovnáš cenu ve všech obchodech a na Windows ti může poslat oznámení, když se hlídaný produkt dostane do slevy. Je to lokální aplikace, která běží na tvém počítači, a je zdarma s licencí MIT.

## Instalace (Windows)

1. Stáhni `Letackomat-Setup-X.Y.Z.exe` z [store.opikula.dev/app/letackomat](https://store.opikula.dev/app/letackomat/), nebo z [GitHub releases](https://github.com/OpiKula2877/letackomat/releases/latest).
2. Spusť ho a dokonči instalaci. Windows může ukázat „Neznámý vydavatel“, protože instalátor není podepsaný: klikni na Další informace a Přesto spustit.
3. Po instalaci se aplikace otevře jako okno a na ploše přibude zástupce. Při prvním spuštění se stáhnou akce, což trvá několik minut.

Nové verze se ukážou v záhlaví aplikace a aktualizuješ je přímo z ní.

Technické informace (API, scraper, data a vývoj) jsou v [docs/technicke-info.md](docs/technicke-info.md).
